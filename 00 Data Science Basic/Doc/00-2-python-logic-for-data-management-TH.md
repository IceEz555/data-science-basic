## 3. ชนิดข้อมูลพื้นฐาน (Data Types) และผลกระทบต่อธุรกิจ

ข้อมูลแต่ละชนิดในระบบมีพฤติกรรมและการคำนวณที่แตกต่างกัน:

1. **`str` (String):** ข้อความ ใช้เก็บชื่อเกม ผู้จัดจำหน่าย หรือหมวดหมู่ เช่น `"Wii Sports"`, `"Nintendo"`
2. **`int` (Integer):** จำนวนเต็ม ใช้เก็บอันดับยอดขาย หรือปีที่เปิดตัว เช่น `1`, `2006`
3. **`float` (Float):** ทศนิยม ใช้เก็บตัวเลขยอดขาย เช่น `82.74` ล้านชุด
4. **`bool` (Boolean):** ค่าความจริง มีเพียง `True` (จริง) หรือ `False` (เท็จ) ใช้ในตรรกะการตัดสินใจ

### ความเสี่ยงจากความผิดพลาดของชนิดข้อมูล (Type Mismatch)
ปัญหาที่พบบ่อยในการรวมข้อมูลจากหลายระบบคือ ตัวเลขถูกแปลงเป็นข้อความโดยไม่ได้ตั้งใจ:
- หากคำนวณแบบข้อความ: `"41.49" + "29.02"` จะให้ผลลัพธ์เป็น `"41.4929.02"` (การต่อข้อความ)
- หากคำนวณแบบตัวเลข: `41.49 + 29.02` จะให้ผลลัพธ์เป็น `70.51`  
การตรวจสอบชนิดข้อมูลจึงเป็นด่านแรกที่ต้องทำเสมอเพื่อป้องกันความผิดพลาดในการคำนวณยอดขาย

## 4. โครงสร้างการเก็บข้อมูล: List และ Dictionary

### 4.1 List (รายการข้อมูลตามลำดับ)
- ใช้วงเล็บ `[ ]`
- เหมาะสำหรับการเก็บตัวเลขลำดับ เช่น ยอดขายของเกม 5 อันดับแรก: `[82.74, 40.24, 35.82, 33.00, 31.37]`
- เข้าถึงข้อมูลผ่านลำดับตำแหน่ง (Index) โดยเริ่มต้นจากลำดับ `0`

### 4.2 Dictionary (คู่ค่าข้อมูล Key-Value)
- ใช้วงเล็บ `{ }` ในรูปแบบ `{"Key": Value}`
- เทียบเท่ากับ **1 แถวของตารางข้อมูล (1 Record)** เช่น:
  ```python
  game = {
      "Rank": 1,
      "Name": "Wii Sports",
      "Platform": "Wii",
      "Global_Sales": 82.74
  }
  ```
- เข้าถึงข้อมูลผ่านชื่อ Key ทำให้โค้ดอ่านเข้าใจง่ายตรงตามความหมายทางธุรกิจ

### 4.3 List of Dictionaries (โครงสร้างฐานข้อมูลระเบียน)
เมื่อรวม Dictionary หลายแถวเข้าใน List จะได้โครงสร้างตารางข้อมูลที่สมบูรณ์ ซึ่งสามารถนำไปสร้างตารางใน Pandas DataFrame หรือบันทึกเข้าฐานข้อมูล SQL ได้ทันที

## 5. โครงสร้างเงื่อนไขสำหรับตรรกะทางธุรกิจ (if-elif-else)

โครงสร้างเงื่อนไขทำหน้าที่เปลี่ยนนโยบายบริษัทเป็นตรรกะคอมพิวเตอร์:
- `if`: ตรวจสอบเงื่อนไขข้อแรก เช่น ยอดขาย $\ge 30$ ล้านชุด (Mega Blockbuster)
- `elif`: ตรวจสอบเงื่อนไขถัดไป เช่น ยอดขาย $\ge 20$ ล้านชุด (Major Hit)
- `else`: ดำเนินการในกรณีที่ไม่ตรงกับเงื่อนไขใดๆ เลย (Standard Success)

**หลักสำคัญ:** ระบบจะตรวจทานจากบนลงล่าง การเรียงลำดับเงื่อนไขตัวเลขต้องเรียงจากค่าสูงสุดลงมาค่าต่ำสุดเสมอ เพื่อป้องกันการดักจับเงื่อนไขผิดพลาด

## 6. โครงสร้างการทำงานซ้ำ (Loops: for loop)

การประมวลผลข้อมูลในธุรกิจต้องทำกับข้อมูลจำนวนมาก คำสั่ง `for loop` ทำหน้าที่นำข้อมูลแต่ละแถวออกมาประมวลผลตามกฎเกณฑ์ทีละรายการจนครบทั้งชุดข้อมูล

## 7. สรุปตรรกะการฝึกปฏิบัติ (Exercise Summary)

### โจทย์ที่ 1: การคำนวณผลรวมและค่าเฉลี่ย
- ข้อมูล: `series_sales = [14.76, 14.64, 14.03, 13.73, 13.51]` (ยอดขายเกมซีรีส์ Call of Duty)
- คำนวณผลรวม: `total_series_sales = sum(series_sales)` -> `70.67 ล้านชุด`
- คำนวณค่าเฉลี่ย: `avg_series_sales = total_series_sales / len(series_sales)` -> `14.13 ล้านชุด`

### โจทย์ที่ 2: การตรวจสอบสถานะ KPI
- ตรวจสอบยอดขายเฉลี่ยเทียบกับเกณฑ์:
  ```python
  if avg_series_sales >= 14.0:
      status = "สถานะ: ผลงานระดับยอดเยี่ยม บรรลุเป้าหมายสูงสุด"
  elif avg_series_sales >= 12.0:
      status = "สถานะ: ผลงานระดับมาตรฐานตามเป้าหมาย"
  else:
      status = "สถานะ: ยอดขายต่ำกว่าเกณฑ์ ต้องทบทวนแผนพัฒนาสินค้า"
  ```
- ผลลัพธ์: ได้รับสถานะ `"ผลงานระดับยอดเยี่ยม บรรลุเป้าหมายสูงสุด"` เนื่องจากค่าเฉลี่ยอยู่ที่ 14.13 ล้านชุด
