## 1. บทนำ: ทำไมต้องเปลี่ยนผ่านจาก Excel สู่ Pandas

Microsoft Excel เป็นเครื่องมือหลักในงานธุรกิจมาอย่างยาวนาน แต่เมื่อปริมาณข้อมูลขยายตัวสูงขึ้น องค์กรเผชิญกับคอขวดที่สำคัญ:

| ประเด็นการดำเนินงาน | Microsoft Excel | Pandas (Python) |
|---|---|---|
| **ขีดจำกัดขนาดข้อมูล** | สูงสุด 1,048,576 แถว หากไฟล์ใหญ่กว่า 200,000 แถว ระบบจะเริ่มช้าลงอย่างเห็นได้ชัด | ประมวลผลได้ตามขนาด RAM ของเครื่อง สามารถรองรับข้อมูลหลักหลายล้านแถวได้อย่างรวดเร็ว |
| **กระบวนการทำงานซ้ำ (Automation)** | ต้องบันทึก Macro หรือทำซ้ำด้วยตนเองทุกรอบการรายงาน | พัฒนาสคริปต์ครั้งเดียว สามารถตั้งเวลาประมวลผลอัตโนมัติ (Automated Data Pipeline) ได้ทันที |
| **ความถูกต้องของข้อมูล (Data Integrity)** | เสี่ยงต่อการลบหรือพิมพ์สูตรผิดพลาดทับเซลล์เดิมโดยไม่ตั้งใจ | ข้อมูลดิบต้นฉบับจะถูกเก็บรักษาไว้โดยไม่มีการเปลี่ยนแปลง (Non-destructive Processing) |
| **การเชื่อมต่อกับระบบอื่น** | ลิงก์เชื่อมโยงข้ามไฟล์มักมีปัญหาเมื่อย้ายตำแหน่งโฟลเดอร์ | เชื่อมต่อโดยตรงกับฐานข้อมูล SQL, Cloud Storage, ERP, และ REST API ได้อย่างมั่นคง |

## 2. ตารางเปรียบเทียบคำสั่งสำคัญ: Excel เทียบกับ Pandas

| งานทางธุรกิจ | คำสั่งใน Microsoft Excel | คำสั่งใน Pandas |
|---|---|---|
| **เปิดและอ่านข้อมูล** | ดับเบิลคลิกเปิดไฟล์ หรือ Power Query | `pd.read_csv(path + "/vgsales.csv")` |
| **ตรวจสอบขนาดข้อมูล** | ดูแถวและคอลัมน์สุดท้ายของชีต | `df.shape` (ส่งกลับจำนวนแถวและจำนวนคอลัมน์ เช่น `16,598, 11`) |
| **ดูภาพรวมโครงสร้างและประเภทข้อมูล** | ดูการจัดรูปแบบ Format Cells | `df.info()` |
| **สรุปสถิติตัวเลขภาพรวม** | สูตร `=AVERAGE()`, `=MEDIAN()`, `=STDEV()` | `df.describe()` |
| **การกรองข้อมูลตามเงื่อนไข** | เมนู Data > AutoFilter | Boolean Indexing เช่น `df[df['Platform'] == 'PS4']` |
| **การจัดการค่าว่าง (Missing Values)** | ค้นหา Blank Cells เพื่อลบหรือแทนค่า | `df.dropna(subset=['Publisher'])` หรือ `df['Year'].fillna(median_year)` |
| **การจัดกลุ่มสรุปผล** | เครื่องมือ Pivot Table | `df.groupby('Genre')['Global_Sales'].agg(['sum', 'mean'])` |
| **การรวมข้อมูลข้ามตาราง** | สูตร `=VLOOKUP()` หรือ `=XLOOKUP()` | `pd.merge(df, publisher_master, on='Publisher', how='left')` |

## 3. ขั้นตอนการตรวจสอบคุณภาพข้อมูลเบื้องต้น (Data Inspection)

การทำงานกับชุดข้อมูลจริง `vgsales.csv` (16,598 แถว) ผ่านคำสั่งตรวจสอบคุณภาพ:

1. **`df.shape`:** ตรวจสอบขนาดของตาราง คืนค่า `(16598, 11)`
2. **`display(df.head(5))`:** แสดงข้อมูลตัวอย่าง 5 แถวแรกในรูปแบบตาราง HTML ที่สวยงาม
3. **`df.info()`:** รายงานว่ามีคอลัมน์ใดที่มีค่าสูญหาย (Non-Null Count น้อยกว่า 16,598) พบว่าคอลัมน์ `Year` และ `Publisher` มีข้อมูลตกหล่น
4. **`df.describe()`:** ตรวจสอบสถิติเชิงพรรณนา เช่น ยอดขายเฉลี่ยทั่วโลก ค่าเบี่ยงเบนมาตรฐาน และยอดขายสูงสุด

## 4. การจัดการข้อมูลสูญหาย (Missing Data Strategy)

ในชุดข้อมูล `vgsales.csv` มีข้อมูลสูญหายใน 2 คอลัมน์สำคัญ:
- `Publisher` (ขาด 58 แถว): ทำการตัดทิ้งด้วย `df.dropna(subset=["Publisher"])` เพื่อป้องกันความผิดพลาดในรายงานบริษัทคู่ค้า
- `Year` (ขาด 271 แถว): เติมเต็มด้วยค่ามัธยฐานของปีวางจำหน่าย `df["Year"].fillna(df["Year"].median())` เพื่อรักษายอดขายรวมไม่ให้ตกหล่น

## 5. การสรุปผลข้อมูลเชิงกลุ่ม (GroupBy) เทียบกับ Pivot Table

การสรุปยอดขายตามประเภทเกม (`Genre`) เทียบเท่ากับการสร้าง Pivot Table:
```python
genre_pivot = df_cleaned.groupby("Genre").agg({
    "Global_Sales": ["sum", "mean"],
    "NA_Sales": "sum",
    "EU_Sales": "sum",
    "JP_Sales": "sum",
    "Name": "count"
})
```
ช่วยให้ผู้บริหารเห็นภาพรวมได้ทันทีว่าประเภทเกมใดสร้างยอดขายสูงที่สุดในแต่ละภูมิภาค

## 6. การเชื่อมโยงตารางข้อมูล (Data Merging) เทียบกับ VLOOKUP / XLOOKUP

การดึงข้อมูลประเทศต้นกำเนิดของบริษัทผู้จัดจำหน่ายจากตาราง Master Table:
```python
df_merged = pd.merge(
    left=df_cleaned,
    right=publisher_master_data,
    on="Publisher",
    how="left"
)
```
การจับคู่ข้อมูล 16,000+ แถวเสร็จสิ้นในเสี้ยววินาทีโดยไม่มีข้อจำกัดเรื่องลำดับคอลัมน์เหมือน VLOOKUP ใน Excel

## 7. สรุปตรรกะการฝึกปฏิบัติ (Exercise Summary)

### โจทย์
1. กรองข้อมูลเฉพาะเกมบนแพลตฟอร์ม **`PS4`** ที่มียอดขายทั่วโลก **`Global_Sales >= 2.0`** ล้านชุด เข้าสู่ตัวแปร `top_ps4_games`
2. คำนวณยอดขายรวมทั่วโลก และค่าเฉลี่ยยอดขายในอเมริกาเหนือ
3. สรุปยอดขายรวม Global Sales แยกตามประเภทเกม (`Genre`)

### โค้ดคำตอบเชิงตรรกะ
```python
# 1. การกรองข้อมูลด้วยเงื่อนไขทางธุรกิจ
top_ps4_games = df_cleaned[(df_cleaned["Platform"] == "PS4") & (df_cleaned["Global_Sales"] >= 2.0)]

# 2. การคำนวณยอดขายรวมและค่าเฉลี่ย
total_global_sales = top_ps4_games["Global_Sales"].sum()
avg_na_sales = top_ps4_games["NA_Sales"].mean()

print(f"ยอดขายรวมทั่วโลก: {total_global_sales:,.2f} ล้านชุด")
print(f"ยอดขายเฉลี่ยในอเมริกาเหนือ: {avg_na_sales:,.2f} ล้านชุด")

# 3. สรุปผลเชิงกลุ่มเปรียบเทียบกับ Pivot Table
ps4_genre_summary = top_ps4_games.groupby("Genre")["Global_Sales"].sum().reset_index()
ps4_genre_summary.columns = ["ประเภทเกม", "ยอดขายรวมทั่วโลก (ล้านชุด)"]
ps4_genre_summary = ps4_genre_summary.sort_values(by="ยอดขายรวมทั่วโลก (ล้านชุด)", ascending=False)
display(ps4_genre_summary)
```

### คำอธิบายผลลัพธ์สำหรับผู้บริหาร
- การวิเคราะห์ข้อมูลยอดขายจริง 16,500+ แถวด้วย Pandas ใช้เวลาประมวลผลไม่ถึงวินาที
- ตรรกะทุกขั้นตอนถูกบันทึกเป็นลายลักษณ์อักษร สามารถนำไปประกอบเป็นกระบวนการทำงานอัตโนมัติ (Automated Data Pipeline) เพื่อรองรับข้อมูลใหม่ในแต่ละเดือนได้อย่างแม่นยำและทำซ้ำได้ (Reproducible)
