# PreTest Live Code: เขียนโค้ด Machine Learning ตามในคลาส

แต่ละ notebook มีคำอธิบายครบทุกขั้น แต่ **ช่องโค้ดเว้นว่างไว้** ให้เขียนตามผู้สอนทีละช่อง

| ไฟล์ | ประเภท | Dataset |
|---|---|---|
| [01_Classification_RainTomorrow_End-to-End_LiveCode](01_Classification_RainTomorrow_End-to-End_LiveCode.ipynb) | Binary Classification | Rain in Australia |
| [02_Regression_Insurance_End-to-End_LiveCode](02_Regression_Insurance_End-to-End_LiveCode.ipynb) | Regression | Medical Insurance |
| [03_Multiclass_Classification_Penguins_LiveCode](03_Multiclass_Classification_Penguins_LiveCode.ipynb) | Multiclass Classification | Palmer Penguins |
| [04_Clustering_Mall_Customers_LiveCode](04_Clustering_Mall_Customers_LiveCode.ipynb) | Clustering | Mall Customers |

## วิธีเริ่ม
1. ดาวน์โหลดหรือ clone โฟลเดอร์นี้ทั้งโฟลเดอร์ (ต้องมีโฟลเดอร์ `Data/` อยู่ข้าง ๆ notebook)
2. เปิด notebook แล้วอ่านคำอธิบายก่อนเขียนโค้ดในแต่ละช่อง
3. ถ้าเปิดบน Google Colab ซึ่งไม่มีโฟลเดอร์ `Data/` ให้ดาวน์โหลดข้อมูลจาก Kaggle ด้วย `kagglehub`
