## 🎯 การสำรวจข้อมูล (Data Exploration) คืออะไร?

**Data Exploration** หรือ **Exploratory Data Analysis (EDA)** คือขั้นตอนแรกในการทำความเข้าใจว่าข้อมูลบรรจุอะไรไว้ และส่วนต่างๆ สัมพันธ์กันอย่างไร มันช่วยเปิดเผย "เรื่องราว" ที่ข้อมูลต้องการสื่อ โดยใช้กราฟและสถิติพื้นฐาน

> 💡 **เปรียบเปรย**: เหมือนกับการอ่านหนังสือคร่าวๆ ก่อนเริ่มอ่านจริงจัง เพื่อให้รู้ว่าหนังสือเล่มนี้พูดถึงอะไร โครงสร้างเป็นอย่างไร

---

## 🔄 กระบวนการสำรวจข้อมูล (EDA Process)

> 📌 **จากรูปภาพ Infographic**: EDA เป็น **วงจรซ้ำ (Iterative Cycle)** ไม่ใช่กระบวนการเส้นตรง

```
┌─────────────────────────────────┐
│   Cleaning & Preprocessing      │  ← ทำความสะอาดข้อมูล
│         ↕ (ไปกลับได้)           │
│         Exploration              │  ← สำรวจและวิเคราะห์
│         ↕ (ไปกลับได้)           │
│    More Cleaning (ถ้าจำเป็น)    │  ← ทำความสะอาดเพิ่มจากสิ่งที่พบ
└─────────────────────────────────┘
```

**ความสำคัญ**: ขณะสำรวจข้อมูล เราอาจพบปัญหาที่ต้องกลับไปทำความสะอาดข้อมูลก่อน เช่น พบค่าผิดปกติ หรือข้อมูลที่หายไป

## ✅ ประโยชน์ของการสำรวจข้อมูล

> 📌 **จากรูปภาพ Infographic**:

| # | ประโยชน์ | รายละเอียด |
|---|----------|-----------|
| 1 | **ระบุ Patterns และ Anomalies** | มองเห็นแนวโน้ม กลุ่ม และความผิดปกติในข้อมูล |
| 2 | **ช่วยตัดสินใจสร้างโมเดลได้ดีขึ้น** | รู้ว่าควรใช้ Algorithm ไหน และต้องเตรียมข้อมูลอย่างไร |
| 3 | **ลดข้อผิดพลาดในอนาคต** | ตรวจพบปัญหาข้อมูลตั้งแต่เนิ่นๆ |

**เครื่องมือที่ใช้:**
- 📊 **Visualization** (กราฟต่างๆ) → มองเห็น Pattern ได้ง่าย
- 📐 **Statistics** (ตัวเลขสรุป) → วัดและเปรียบเทียบข้อมูล

## 🔬 ระดับความลึกของการวิเคราะห์

> 📌 **จากรูปภาพ Infographic**:

### 1. Univariate Analysis — วิเคราะห์ตัวแปรเดียว

- โฟกัสที่ **ตัวแปรเดียว**
- ดู: การกระจายตัว (Distribution) และค่ากลาง (Central Tendency)

### 2. Bivariate Analysis — วิเคราะห์สองตัวแปร

- ดูความสัมพันธ์ระหว่าง **สองตัวแปร**

### 3. Multivariate Analysis — วิเคราะห์หลายตัวแปร

- วิเคราะห์ปฏิสัมพันธ์ที่ซับซ้อนระหว่าง **มากกว่าสองตัวแปร**

## 📋 ชุดข้อมูลที่ใช้: Golf Play Dataset

| คอลัมน์ | ประเภท | คำอธิบาย |

df.head()

df.info()

## 📊 ประเภทของข้อมูล (Data Types)

การเข้าใจประเภทข้อมูลช่วยให้เลือกวิธีวิเคราะห์ที่ถูกต้อง

```
ข้อมูล
├── เชิงตัวเลข (Numerical)
│   ├── Continuous (ต่อเนื่อง): อุณหภูมิ, ความชื้น, น้ำหนัก
│   └── Discrete (ไม่ต่อเนื่อง): จำนวนลูก, จำนวนห้อง
└── เชิงหมวดหมู่ (Categorical)
    ├── Nominal (ไม่มีลำดับ): สี, ประเภทสภาพอากาศ
    └── Ordinal (มีลำดับ): เกรด(A/B/C), ระดับความพอใจ
```

## 📝 สรุปบทเรียน

- **Data Exploration** คือการทำความเข้าใจข้อมูลก่อนวิเคราะห์เชิงลึก
- เป็น **วงจรซ้ำ** ไม่ใช่กระบวนการเส้นตรง
- ประโยชน์: ระบุ Pattern, ช่วยตัดสินใจสร้างโมเดล, ลดข้อผิดพลาด
- ใช้ไลบรารี **NumPy, Pandas, Matplotlib, Seaborn** ใน Python
- การวิเคราะห์แบ่งเป็น 3 ระดับ: **Univariate → Bivariate → Multivariate**
- **Correlation Heatmap, Summary Stats, Histogram, Cluster Analysis** คือสิ่งที่ต้องทำก่อน (Critical)
