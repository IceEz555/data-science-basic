## 📌 Data Science คืออะไร?

**Data Science** คือสาขาวิชาที่นำ **ข้อมูล (Data)** มาวิเคราะห์และตีความ เพื่อสร้าง **ความรู้ (Knowledge)** และ **ข้อมูลเชิงลึก (Insights)** ที่มีคุณค่าต่อการตัดสินใจ

Data Science เป็น **ศาสตร์สหวิทยาการ (Interdisciplinary Field)** ที่รวมความรู้จากหลายสาขา ได้แก่:
- 📊 **สถิติ (Statistics)** — เพื่อวิเคราะห์และตีความข้อมูล
- 💻 **วิทยาการคอมพิวเตอร์ (Computer Science)** — เพื่อประมวลผลข้อมูล
- 🏢 **ความรู้ด้านธุรกิจ (Domain/Business Knowledge)** — เพื่อตีความผลลัพธ์ให้ถูกต้องตามบริบท

---

## 🔄 Data Science vs Machine Learning vs Data Analysis

แม้คำเหล่านี้จะดูคล้ายกัน แต่มีขอบเขตที่แตกต่างกัน:

| คำศัพท์ | ความหมาย |
|---|---|
| **Data Analysis (การวิเคราะห์ข้อมูล)** | การสำรวจและอธิบายข้อมูลที่มีอยู่ เพื่อหาแนวโน้มและรูปแบบ |
| **Machine Learning (การเรียนรู้ของเครื่อง)** | การสร้างโมเดลที่สามารถเรียนรู้จากข้อมูลและทำนายผลลัพธ์ |
| **Data Science (วิทยาศาสตร์ข้อมูล)** | วงกว้างที่สุด ครอบคลุมทั้งสองอย่างข้างต้น รวมถึงการจัดการข้อมูล การนำเสนอ และการสร้างผลกระทบต่อธุรกิจ |

> 💡 ง่ายๆ คือ: **Machine Learning** และ **Data Analysis** คือส่วนหนึ่งของ **Data Science**

## ⚔️ Data Science vs วิธีสถิติแบบดั้งเดิม

| หัวข้อ | วิธีสถิติแบบดั้งเดิม | Data Science |
|---|---|---|
| **ปริมาณข้อมูล** | ข้อมูลน้อย (Small Data) | ข้อมูลขนาดใหญ่ (Big Data) |
| **เครื่องมือ** | สูตรสถิติ, การคำนวณด้วยมือ | Python, R, SQL, ML Libraries |
| **เป้าหมาย** | ทดสอบสมมติฐาน (Hypothesis Testing) | ค้นพบรูปแบบและพยากรณ์ผลลัพธ์ |
| **ความสามารถ** | อธิบายปรากฏการณ์ที่เกิดขึ้นแล้ว | ทำนายสิ่งที่อาจเกิดขึ้นในอนาคต |
| **กระบวนการ** | ออกแบบการทดลองล่วงหน้า | วนซ้ำและปรับปรุงโมเดลอย่างต่อเนื่อง |

## 🌟 ความสำคัญของ Data Science

Data Science มีความสำคัญในโลกปัจจุบันอย่างมาก เนื่องจาก:

### 🏥 ด้านสุขภาพ (Healthcare)
- การวินิจฉัยโรคจากภาพถ่ายทางการแพทย์ด้วย AI
- การค้นพบยาตัวใหม่จากการวิเคราะห์ข้อมูลโมเลกุล
- การพยากรณ์การระบาดของโรค

### 🛒 ด้านธุรกิจและการตลาด (Business & Marketing)
- ระบบแนะนำสินค้า (Recommendation Systems) เช่น Netflix, Shopee
- การวิเคราะห์พฤติกรรมลูกค้า
- การพยากรณ์ยอดขาย

### 🏦 ด้านการเงิน (Finance)
- การตรวจจับการทุจริต (Fraud Detection)
- การประเมินความเสี่ยงการปล่อยสินเชื่อ
- การวิเคราะห์ตลาดหุ้น

### 🌍 ด้านสิ่งแวดล้อม (Environment)
- การพยากรณ์สภาพอากาศ
- การวิเคราะห์การเปลี่ยนแปลงสภาพภูมิอากาศ
- การจัดการทรัพยากรธรรมชาติ

## 🎓 ทักษะที่ Data Scientist ต้องมี

Data Scientist ที่ดีควรมีทักษะในหลายด้าน:

```
📐 คณิตศาสตร์ & สถิติ
   ├── Probability (ความน่าจะเป็น)
   ├── Linear Algebra (พีชคณิตเชิงเส้น)
   └── Statistical Inference (การอนุมานทางสถิติ)

💻 การเขียนโปรแกรม
   ├── Python (ภาษาหลักที่ใช้บ่อยที่สุด)
   ├── R (เหมาะสำหรับงานวิเคราะห์สถิติ)
   └── SQL (สำหรับจัดการฐานข้อมูล)

🤖 Machine Learning
   ├── Supervised Learning
   ├── Unsupervised Learning
   └── Model Evaluation

📊 การสื่อสารและนำเสนอข้อมูล
   ├── Data Visualization (Matplotlib, Seaborn, Tableau)
   └── Storytelling with Data

🏢 ความรู้เฉพาะด้าน (Domain Knowledge)
   └── เข้าใจบริบทของปัญหาที่กำลังแก้ไข
```

## 🤔 Data Scientist ทำอะไรบ้าง?

กระบวนการทำงานของ Data Scientist โดยทั่วไป:

1. **🎯 กำหนดปัญหา** — เข้าใจว่าธุรกิจต้องการอะไร
2. **📦 รวบรวมข้อมูล** — หาและเก็บข้อมูลที่เกี่ยวข้อง
3. **🧹 ทำความสะอาดข้อมูล** — จัดการข้อมูลที่ขาดหาย หรือผิดปกติ
4. **🔍 สำรวจข้อมูล** — วิเคราะห์เพื่อเข้าใจรูปแบบของข้อมูล
5. **🤖 สร้างโมเดล** — สร้าง Machine Learning Model
6. **📈 ประเมินผล** — วัดประสิทธิภาพของโมเดล
7. **🚀 นำไปใช้งาน** — Deploy โมเดลเข้าสู่ระบบจริง
8. **👀 ติดตามผล** — ดูแลและปรับปรุงโมเดลต่อเนื่อง

> 📚 กระบวนการข้างต้นคือ **Data Science Pipeline** ซึ่งจะเรียนในบทถัดไป!
